# 🧪 Session 01 — In-Class Task
### Deep Learning Using Neural Networks | Aptech
### Task Title: "Mapping the Deep Learning Universe"
### Duration: 40–50 minutes

---

> **Instructor Note:** This task requires NO coding. It is designed to cement conceptual understanding before students touch code. It is collaborative, visual, and discussion-based. Have students work in pairs or groups of 3.

---

## 🎯 Learning Objectives

By the end of this task, students will be able to:
- [ ] Draw and explain the AI → ML → DL hierarchy from memory
- [ ] Identify real-world applications of DL in their everyday lives
- [ ] Classify ethical concerns by category
- [ ] Articulate the difference between "programmed" and "learned" intelligence

---

## 🛠️ What You Need

- ✅ Paper and pen (or whiteboard if available)
- ✅ Access to a browser (for the research portion)
- ✅ The Lecture Notes (01_Lecture_Notes.md)

## 📋 PART 4 — Class Discussion (10 minutes)

Each group presents their **Ethics Tribunal decisions** to the class.

### Discussion Questions for the Class:
1. Did different groups reach **different decisions** for the same scenario? Why?
2. Which scenario had the **most disagreement**? What does that tell us?
3. Can you think of a DL application that has **no ethical concerns** at all?
4. If YOU were building an AI system, which ethical pillar would you prioritize FIRST?
